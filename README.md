# Elementarium
---
## 🎮 How to Play
1. **Select an Element:** Click on any element button from the category tabs at the bottom.
2. **Draw:** Left-click and drag on the canvas to pour or place elements.
3. **Erase:** Right-click and drag to clear pixels.
4. **Change Brush Size:** Scroll the mouse wheel or use `+` / `-` keys.
---
## ⌨️ Keyboard Shortcuts
Keep your hands on the keyboard for maximum efficiency:
* **`P`** : Pause / Resume the simulation
* **`R`** : Clear all pixels (Requires confirmation)
* **`S`** : Open Settings menu
* **`Ctrl + Z`** or **`Z`** : **Undo** your last brush stroke
* **`+`** / **`-`** : Increase / Decrease brush size
